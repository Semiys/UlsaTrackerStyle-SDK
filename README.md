# UlsaTrackerStyle SDK

Сервис продуктовой аналитики для мобильных приложений. SDK отправляет события об открытии экранов, нажатиях кнопок и успешных действиях; сервер сохраняет их, а веб-панель показывает счётчики и графики. Первый клиент — **«Дом Коллекционера»**, Android/KMP.

## Версии для запуска

| Работа | Тег образа | Что открывается |
|---|---|---|
| ЛР4 | `0.0.4` | Кабинет, Android/Web SDK, отдельная статистика в Grafana |
| ЛР3 | `0.0.3` | Прежние функции, отдельный ClickHouse и постоянное хранение |
| ЛР2 | `0.0.2` | Отправка события, статистика и объяснение отказа; хранение в JSON |
| ЛР1 | `0.0.1` | Первая страница: название, описание, версия и статус разработки |

Опубликованные теги **0.0.1, 0.0.2, 0.0.3 и 0.0.4** содержат **linux/amd64 и linux/arm64**. Docker выбирает архитектуру автоматически. На Windows/macOS нужен Docker Desktop в режиме Linux-контейнеров, на Linux — Docker Engine. Node.js и зависимости находятся внутри образа.

## Запуск

**ЛР4, версия 0.0.4:** кабинет разработчика, ClickHouse и Grafana. Нужен Docker Compose; Node.js, APK и ручная настройка базы для демонстрации не требуются. Порты **8080** и **3000** должны быть свободны.

Репозиторий: https://github.com/Semiys/UlsaTrackerStyle-SDK

Ветка: lab4

Pull Request: https://github.com/Semiys/UlsaTrackerStyle-SDK/pull/4

Образ: semiys/ulsatrackerstyle-sdk:0.0.4

Страница образа: https://hub.docker.com/r/semiys/ulsatrackerstyle-sdk

```bash
git clone -b lab4 https://github.com/Semiys/UlsaTrackerStyle-SDK
```

```bash
cd UlsaTrackerStyle-SDK
```

```bash
docker compose up -d --wait
```

Откройте **http://localhost:8080**. Демонстрационная статистика доступна без входа: **http://localhost:8080/dashboard**; отдельная Grafana — **http://localhost:3000**. На свежем томе список пуст: создайте событие кнопкой «Отправить событие», вернитесь к статистике и дождитесь обновления панели. «Пример отказа» показывает ошибочный сценарий без записи в БД.

Чтобы подключить своё приложение: **Регистрация → проект → приложение → ключ → статистика**. Для сайта доступна [JavaScript SDK](sdk/js/README.md), для Android — [Kotlin SDK](sdk/kotlin/README.md). [Подробный путь по кабинету](docs/CONSOLE.md) и [список ручных проверок](docs/LAB4_CHECKLIST.md).

Остановить контейнеры, сохранив данные:

```bash
docker compose down
```

Повторный запуск — та же команда `docker compose up -d --wait`. Не добавляйте `-v`: он удаляет постоянные тома. Для переноса нужны `dbdata` (события), `appdata` (владельцы, проекты, ключи) и `grafanadata` (настройки Grafana). [Устройство выпуска и ограничения](docs/LAB4.md).

## Запуск ЛР2

**1. Скачайте образ.**

```bash
docker pull semiys/ulsatrackerstyle-sdk:0.0.2
```

**2. Запустите контейнер.** Порт 8080 должен быть свободен.

```bash
docker run --rm -p 8080:8080 semiys/ulsatrackerstyle-sdk:0.0.2
```

**3. Откройте [http://localhost:8080](http://localhost:8080).** Остановка контейнера — **Ctrl+C**. В этом коротком запуске контейнер и его данные удаляются после остановки. Для сохранения событий используйте [запуск с Docker volume](docs/RUNNING.md#сохранение-событий).

### Как проверить ЛР2

1. Нажмите **«Отправить событие»**, сохраните предложенные значения. Откроется статистика с подтверждением и новой записью.
2. На странице **«Статистика»** посмотрите счётчики, дневной график и последние события; переключите период 7/30 дней.
3. Откройте **«Пример отказа»**, вернитесь к форме и отправьте пустое название. Сервер объяснит причину отказа, число событий останется прежним.

ЛР2 использует демонстрационный проект с публичными учебными ключами и предназначена для локального показа. После первого запуска статистика пуста; примеры событий автоматически не создаются.

## Запуск ЛР1

**1. Скачайте образ.**

```bash
docker pull semiys/ulsatrackerstyle-sdk:0.0.1
```

**2. Запустите контейнер.** Если ранее запущена ЛР2 на 8080, сначала остановите её.

```bash
docker run --rm -p 8080:8080 semiys/ulsatrackerstyle-sdk:0.0.1
```

**3. Откройте [http://localhost:8080](http://localhost:8080).** На странице видны название системы, описание, версия **0.0.1** и статус разработки. Остановка — **Ctrl+C**.

## Если порт занят

Для ЛР2 используйте другой порт компьютера, например 8081:

```bash
docker run --rm -p 8081:8080 semiys/ulsatrackerstyle-sdk:0.0.2
```

Откройте [http://localhost:8081](http://localhost:8081). Для ЛР1 замените тег на `0.0.1`. [Выбор свободного порта из диапазона](docs/RUNNING.md#выбор-свободного-порта) описан отдельно.

## Состояние разработки

Сервер — **0.7.1**, образ ЛР4 — **0.0.4**, Kotlin SDK для Android/JVM — **0.2.0**, JavaScript SDK — **0.1.0**. Обе SDK используют прежний HTTP-контракт v1. iOS-адаптер пока не реализован. Пакеты не опубликованы в Maven/npm: доступны Gradle composite build, JS-скрипт, ES module и локальный npm-пакет.

События хранятся в ClickHouse, учётные записи и настройки кабинета — в SQLite из Node.js. Сейчас работает один процесс приёма. Горизонтальное масштабирование, восстановление пароля и подтверждение почты ещё не реализованы; учебный Compose не является готовой конфигурацией публичного SaaS. Фотографии, содержимое коллекции, поля форм и рекламные ID автоматически не собираются.
