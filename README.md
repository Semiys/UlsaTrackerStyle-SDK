# UlsaTrackerStyle SDK

Сервис продуктовой аналитики для мобильных приложений. SDK отправляет события об открытии экранов, нажатиях кнопок и успешных действиях; сервер сохраняет их, а веб-панель показывает счётчики и графики. Первый клиент — **«Дом Коллекционера»**, Android/KMP.

## Версии для запуска

| Работа | Тег Docker Hub | Что открывается |
|---|---|---|
| ЛР2 | `0.0.2` | Отправка события, статистика и объяснение отказа; хранение в JSON |
| ЛР1 | `0.0.1` | Первая страница: название, описание, версия и статус разработки |

Оба тега содержат **linux/amd64 и linux/arm64**. Docker выбирает архитектуру автоматически. На Windows/macOS нужен Docker Desktop в режиме Linux-контейнеров, на Linux — Docker Engine. Node.js и зависимости находятся внутри образа.

## Запуск ЛР2

**1. Скачайте образ.**

```bash
docker pull semiys/ulsatrackerstyle-sdk:0.0.2
```

**2. Запустите контейнер.** Порт 8080 должен быть свободен.

```bash
docker run --rm -p 8080:8080 semiys/ulsatrackerstyle-sdk:0.0.2
```

**3. Откройте [http://localhost:8080](http://localhost:8080).** Остановка контейнера — **Ctrl+C**. В этом коротком запуске контейнер и его данные удаляются после остановки. Для сохранения событий используйте [запуск с Docker volume](docs/RUNNING.md#сохранение-событий).

### Как проверить ЛР2

1. Нажмите **«Отправить событие»**, сохраните предложенные значения. Откроется статистика с подтверждением и новой записью.
2. На странице **«Статистика»** посмотрите счётчики, дневной график и последние события; переключите период 7/30 дней.
3. Откройте **«Пример отказа»**, вернитесь к форме и отправьте пустое название. Сервер объяснит причину отказа, число событий останется прежним.

ЛР2 использует демонстрационный проект с публичными учебными ключами и предназначена для локального показа. После первого запуска статистика пуста; примеры событий автоматически не создаются.

## Запуск ЛР1

**1. Скачайте образ.**

```bash
docker pull semiys/ulsatrackerstyle-sdk:0.0.1
```

**2. Запустите контейнер.** Если ранее запущена ЛР2 на 8080, сначала остановите её.

```bash
docker run --rm -p 8080:8080 semiys/ulsatrackerstyle-sdk:0.0.1
```

**3. Откройте [http://localhost:8080](http://localhost:8080).** На странице видны название системы, описание, версия **0.0.1** и статус разработки. Остановка — **Ctrl+C**.

## Если порт занят

Для ЛР2 используйте другой порт компьютера, например 8081:

```bash
docker run --rm -p 8081:8080 semiys/ulsatrackerstyle-sdk:0.0.2
```

Откройте [http://localhost:8081](http://localhost:8081). Для ЛР1 замените тег на `0.0.1`. [Выбор свободного порта из диапазона](docs/RUNNING.md#выбор-свободного-порта) описан отдельно.

## Состояние разработки

Исходники сервера — **0.4.2**, Kotlin SDK — **0.2.0**, демонстрационный APK — **1.2**. Опубликованный образ ЛР2 `0.0.2` содержит сервер **0.4.1**. Оформленные выпадающие списки темы и периода из 0.4.2 доступны при сборке текущих исходников.

SDK реализована для **Android и JVM**: постоянная очередь, пакетная отправка в фоне, повторы и подтверждения. iOS и JavaScript SDK запланированы. Фотографии, содержимое коллекции, пользовательский ввод и рекламные ID SDK не собирает.
