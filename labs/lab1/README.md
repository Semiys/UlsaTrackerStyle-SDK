# Первая страница ЛР1

Исходная первая страница и зависимости сохранены из коммита 54a9a90. Сборка содержит только Express и статическую страницу: название системы, описание, версию 0.0.1 и статус разработки. Оформление обновлено по палитрам «Дома Коллекционера»: голубой акцент в светлой теме и красный в тёмной. Тема выбирается системной настройкой браузера.

Из корня репозитория:

```bash
docker buildx build --platform linux/amd64,linux/arm64 -t semiys/ulsatrackerstyle-sdk:0.0.1 --push ./labs/lab1
```

Проверка опубликованного образа:

```bash
docker pull semiys/ulsatrackerstyle-sdk:0.0.1
docker run --rm -p 8080:8080 semiys/ulsatrackerstyle-sdk:0.0.1
```

Откройте http://localhost:8080. Dockerfile этого каталога полностью приведён в отчёте ЛР1. ЛР2 собирается отдельной целью lab2 из корневого Dockerfile.
