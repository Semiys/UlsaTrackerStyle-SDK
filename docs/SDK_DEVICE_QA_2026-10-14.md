## Стенд

- Устройство: TECNO LH7n, Android 14, физический телефон по USB.
- Приложение «Дом Коллекционера»: обычный debug APK 1.3 (versionCode 5), пакет `com.example.domcollection`.
- SDK: 0.2.0; сервер: 0.5.0; Docker Hub образ: `semiys/ulsatrackerstyle-sdk:0.0.3`.
- Сервер: Compose `mispisit-sarantsev`, приложение на порту 8080 и ClickHouse 26.8.26.12; том `mispisit-sarantsev_dbdata`.
- Связь телефона: `adb reverse tcp:8080 tcp:8080`, endpoint `http://127.0.0.1:8080`, публичный учебный ключ проекта `lab3-demo`.
- Debug APK собран и установлен обновлением без удаления пользовательских данных. Снимки экрана телефона не делались; интерфейс проверялся по дереву UIAutomator.

## Итоговые счётчики

До проверки: одно ранее созданное веб-событие. После доставки всех тестовых событий: 30 событий, из них 29 Android и одно прежнее web; 16 открытий экранов, 11 кликов (включая прежний веб-клик), три успешных действия: два создания и одно редактирование. Пять сессий включают прежнюю веб-сессию и запуски телефона.

Тестовые события оставлены в учебном проекте для просмотра панели. Удаление моделей из коллекции не удаляет историю аналитики. Сервер и база восстановлены, debug-приложение установлено, USB reverse сохранён до отключения телефона.

## Что ещё не проверялось этим прогоном

- Отдельный контролируемый сценарий возврата после 30 минут фона.
- Полный импорт/экспорт ZIP и смена темы при недоступном сервере.
- Измерения батареи, трафика, CPU/RAM и сравнение производительности со сборкой без SDK.
- iOS: настоящего адаптера пока нет; JVM и Android не подтверждают работу iOS.
- Миллионы пользователей, реальные нагрузки сервера, разные модели телефонов.
- opt out и HTTP 429 физически на этом телефоне: для этих ветвей имеются отдельные тесты библиотеки.

Команда JVM-тестов в этом прогоне завершилась успешно с `UP-TO-DATE`; это повторное использование результатов, а не новый запуск всех тестов.

Release-сборка по текущему коду не отправляет эту продуктовую аналитику. Локальный адрес и учебный ключ предназначены для debug-проверки.
