## Повторить серверный прогон

Все команды выполняются из корня репозитория. Используются отдельные порты 18085/13000 и тома с префиксом ulsa-lab4-qa. Основной стенд не используется для тестовых записей.

```bash
docker compose -p ulsa-lab4-qa -f docker-compose.yml -f docker-compose.lab4-test.yml -f docker-compose.full-test.yml build app checks
```

```bash
docker compose -p ulsa-lab4-qa -f docker-compose.yml -f docker-compose.lab4-test.yml -f docker-compose.full-test.yml up -d --wait app dashboard
```

```bash
docker compose -p ulsa-lab4-qa -f docker-compose.yml -f docker-compose.lab4-test.yml -f docker-compose.full-test.yml run --rm --no-deps checks
```

Остановка — те же файлы и имя проекта с командой `stop`. Не добавляйте `-v`. Простой `npm test` без переменных настоящего стенда пропускает интеграционные проверки; полный результат выше получен с работающими ClickHouse и Grafana.

Для Kotlin нужны JDK/Android SDK и Gradle wrapper; [настройка библиотеки](../sdk/kotlin/README.md). Интеграционный тест требует отдельный пустой HTTP endpoint и переменные ULSA_TEST_ENDPOINT, ULSA_TEST_INGEST_KEY, ULSA_TEST_READ_KEY. Без них этот тест пропускается; в описанном прогоне все три были заданы.

## Панель аналитики 0.7.4 — 24.10.2026

Проверены изменения визуализации и запросов; полный прогон 77 тестов выше относится к 0.7.2, а не к повторному тестированию всего продукта в 0.7.4.

- Динамика — линейный временной ряд без сглаживания, четыре ряда (все события, открытия, нажатия, успешные действия), заметные точки, целые значения и ноль у основания шкалы. Подтипы входят в общее количество; ряды не складываются.
- ClickHouse возвращает каждый день выбранного периода, включая дни без событий. Границы периода и суммы проверены через настоящий API Grafana. Пустая неделя 2010 года содержит семь нулей в каждом ряду.
- Семь целевых проверок `test/grafana.test.js` прошли: 7 passed, 0 failed, 0 skipped. Проверены все запросы панелей, совпадение со счётчиками API, повторная отправка без удвоения, отказ неверной формы и ограничения пользователя БД.
- В браузере проверены периоды 7/30/90 дней, сохранение периода после обновления страницы, кнопки обновления и переключения темы. Полноэкранная ссылка получает тот же период и тему. Кнопки выбора периода имеют оформленное активное состояние и подписи.
- Проверены светлая и тёмная темы, отдельная статистика Website B с одним событием и общая панель с несколькими типами событий. Кольцевая диаграмма использует те же цвета для стандартных типов, что и линейный график. В полноэкранной Grafana клик по легенде выделяет ряд, повторный клик возвращает остальные.
- В личном кабинете на ширине 390 px горизонтального переполнения страницы нет (ширина содержимого 375 px, iframe 341.6 px). График, легенда и кольцевая диаграмма читаемы при одном событии. Временный размер окна и светлая тема восстановлены.
- Прогоны с записью выполнялись на ulsa-lab4-qa. Тестовый стенд остановлен без удаления томов; основной оставлен с локальной версией 0.7.4.

Повторить целевые проверки на изолированном стенде:

```bash
docker compose -p ulsa-lab4-qa -f docker-compose.yml -f docker-compose.lab4-test.yml build checks
docker compose -p ulsa-lab4-qa -f docker-compose.yml -f docker-compose.lab4-test.yml run --rm --no-deps checks node --test test/grafana.test.js
```

Перед командой запуска проверок должны работать app/db/dashboard из раздела повторного серверного прогона. В браузере для полного произвольного периода используйте «На весь экран»: быстрые кнопки сайта задают 7/30/90 дней. Группировка остаётся дневной, первый и последний день могут быть неполными; нули означают отсутствие принятых событий, а не доказанную работу SDK в этот день.


## Выпуск 0.7.5 — 24.10.2026

- Полный серверный прогон `node --test --test-concurrency=1 'test/*.test.js'`: **68 passed, 0 failed, 0 skipped**. Работали настоящие ClickHouse и Grafana на отдельном стенде ulsa-lab4-qa, включая сохранённый DuckDB backend.
- Целевой набор Grafana: 14 тестов, включая 7/30/90 дней с одинаковым временем окончания последнего дня UTC, физические дубликаты и изоляцию событий другого проекта.
- Карта активности: семь дней недели и все 24 часа, точные количества и нулевые клетки. Сравнение периодов сдвигает предыдущий календарный интервал на текущую шкалу; последний день обоих интервалов заканчивается в одинаковое время UTC.
- Проверены два одновременных обновления всех 14 панелей. На экземпляре app общий пул POST-запросов к Grafana ограничен двумя соединениями, очередь ограничена 64 ожидающими запросами. Это ограничение ресурсов одного экземпляра, а не испытание нагрузки миллионов пользователей.
- В браузере проверены светлая панель, реальные счётчики, линии сравнения и карта активности. Скриншот для отчёта снят со светлой темы. Автообновление — каждые 30 секунд.
- Kotlin SDK не менялась: её последний полный прогон из 18 тестов указан выше. Новый APK на физическом телефоне и полная интеграция на физическом ARM в этот прогон не входили.
