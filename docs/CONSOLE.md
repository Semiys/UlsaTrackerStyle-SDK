# Кабинет: первое приложение и первое событие

## 1. Запустите сервис и войдите

Выполните [команды запуска](../README.md#запуск). Откройте http://localhost:8080, нажмите «Регистрация». Укажите имя, почту и пароль от 12 до 128 символов. Это локальная учётная запись: подтверждение почты и восстановление пароля ещё не реализованы. Для собственного кабинета общего пароля администратора нет.

Демонстрационные функции доступны без входа. Их события относятся к учебному проекту и не смешиваются с вашими приложениями.

## 2. Создайте проект и приложение

В кабинете создайте проект, например «Дом Коллекционера». Откройте проект, заполните «Новое приложение»:

| Поле | Android | Web |
|---|---|---|
| Название | Дом Коллекционера · Android | Сайт коллекционера |
| Платформа | Android | Web |
| Идентификатор | package name вашего приложения | точный origin, например http://localhost:8080 |

Origin содержит протокол, имя хоста и порт, без пути. `localhost` и `127.0.0.1` — разные origin. Для iOS можно создать запись, но готового iOS-адаптера пока нет.

После создания сохраните ключ: полностью он показывается **один раз**. В списке останется маска. Ключ разрешает только отправку событий этого приложения; пароль кабинета и ключ чтения в SDK не вставляются.

## 3. Подключите SDK

### Android

Подключите библиотеку через [Gradle composite build](../sdk/kotlin/README.md#локальное-подключение-к-android-проекту). На странице приложения есть пример `createAndroidTracker` с endpoint и вашим ключом. Создайте один экземпляр в `Application`, затем вызывайте `screen`, `click`, `track` в нужных местах.

Для уже подготовленного debug-приложения «Дом Коллекционера» задайте в его игнорируемом `local.properties`:

```properties
ulsaTracker.sdkPath=D:/MyTracer SDK CopyStyle/sdk/kotlin
ulsaTracker.endpoint=http://127.0.0.1:8080
ulsaTracker.ingestKey=ВАШ_НОВЫЙ_КЛЮЧ_ПРИЛОЖЕНИЯ
```

При USB-подключении выполните `adb reverse tcp:8080 tcp:8080`, затем пересоберите и установите **debug** APK. Серверные изменения не обновляют ключ внутри уже установленного APK. В релизном приложении локальная аналитика по-прежнему отключена; этот выпуск не меняет его настройки.

### Сайт

Создайте Web-приложение с origin своего сайта и подключите [JavaScript SDK](../sdk/js/README.md). Доступны script, ES module и локальная установка пакета для сборщика. Для HTTP на localhost явно укажите `allowHttp: true`; публичное подключение используйте по HTTPS.

Быстрая проверка: откройте http://localhost:8080/sdk-demo, создайте для неё Web-приложение с origin `http://localhost:8080`, вставьте ключ, подключитесь и нажмите тестовую кнопку. Это настоящая отправка событий JavaScript SDK. Содержимое полей не собирается.

## 4. Проверьте статистику

Откройте приложение → «Открыть статистику». Панель Grafana показывает только события выбранного приложения. Обновление — каждые 10 секунд; проверьте период, если старые события не видны. Число сеансов не равно числу уникальных людей.

«Отправить тестовое событие» проверяет сервер, БД и панель. Оно помечено `source=console_test` и не доказывает работу SDK на телефоне. Для полного сценария выполните действие в подключённом приложении или на сайте и проверьте его имя/время в таблице событий.

## 5. Управляйте доступом

- «Заменить ключ» немедленно прекращает приём по старому ключу. Новый ключ сохраните и обновите в клиентах.
- «Отозвать» прекращает приём по выбранному ключу; просмотр прежних событий сохраняется.
- Архивирование проекта прекращает приём событий всех его приложений. Статистика остаётся доступна владельцу. Снятие галочки возвращает приём по действующим ключам.
- «Выйти» отзывает текущий сеанс. Другой владелец не может открыть ваши проекты, API статистики или источник Grafana.

## Ограничения учебного развёртывания

Один серверный процесс, до 30 проектов владельца и 20 приложений в проекте. Учётные данные хранятся в постоянном SQLite, события — в ClickHouse. Для публичной установки нужны HTTPS, собственные секреты вместо учебных `app/app`, резервные копии трёх постоянных томов и отдельная проверка нагрузки. Механизма сброса пароля и распределённого хранилища сессий пока нет. [Архитектура и проверки](LAB4.md).
