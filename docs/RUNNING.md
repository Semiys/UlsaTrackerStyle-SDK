# Запуск и сохранение данных

Короткие команды для ЛР1 и ЛР2 находятся в [README](../README.md). Здесь описаны дополнительные варианты запуска ЛР2.

## Сохранение событий

Остановите прежнюю проверку на порту 8080. Запустите именованный контейнер с отдельным Docker volume:

```bash
docker run -d --name ulsa-tracker-lab2 --memory 512m --cpus 2 -p 8080:8080 --mount type=volume,source=ulsa-tracker-lab2-data,target=/app/data semiys/ulsatrackerstyle-sdk:0.0.2
```

Откройте http://localhost:8080. Контейнер появится в Docker Desktop. Имя `ulsa-tracker-lab2` должно быть свободно; если такой контейнер уже существует, используйте `docker start` или выберите другое имя.

Остановить:

```bash
docker stop ulsa-tracker-lab2
```

Запустить повторно:

```bash
docker start ulsa-tracker-lab2
```

События лежат в `/app/data/events.json`, настройки проекта — в `access.json`. Они сохраняются в томе `ulsa-tracker-lab2-data` при пересоздании контейнера. Для пересоздания остановите и удалите только контейнер, затем повторите запуск с тем же томом. Не удаляйте том с нужными событиями. На одном томе должен работать один сервер.

После перезапуска откройте форму заново: токен ранее открытой формы перестаёт действовать. В коротком запуске из README используется `--rm` без тома — после остановки данные этого контейнера удаляются.

## Выбор свободного порта

Для фиксированного другого порта измените левую часть `-p`, например `-p 8081:8080`, и откройте http://localhost:8081.

Для автоматического выбора из диапазона:

```bash
docker run -d --name ulsa-tracker-port-preview -p 127.0.0.1:8080-8180:8080 semiys/ulsatrackerstyle-sdk:0.0.2
```

Узнать выбранный порт:

```bash
docker port ulsa-tracker-port-preview 8080/tcp
```

Если получен `127.0.0.1:8082`, откройте http://localhost:8082. Docker выбирает один свободный порт из диапазона; выбор самого младшего номера не гарантируется. На Docker Desktop порт, занятый обычной программой Windows, может потребовать другого диапазона. При полностью занятом диапазоне запуск завершается ошибкой. Имя проверочного контейнера должно быть свободно.

Запуск с диапазоном ограничивает доступ этим компьютером. Основная команда для проверки работы из README использует один порт `8080:8080`.

## Демонстрационный режим и ограничения

Опубликованная ЛР2 включает отдельный демонстрационный проект с публичными учебными ключами. Панель доступна сразу, форма использует подписанный токен. Демонстрация предназначена для локального показа; обычная сборка `runtime` создаёт отдельные ключи отправки и просмотра и требует ключ просмотра на панели.

Повтор того же `eventId` с тем же содержимым учитывается один раз. Изменённое содержимое с прежним ID отклоняет весь пакет. API подтверждает записи после сохранения файла. Повреждённое хранилище останавливает запуск и сохраняет файл для диагностики.

Предел JSON-хранилища — **10 000 событий или 16 МиБ**, очередь — **32 операции**. Сессии обозначают разные `sessionId`, а не пользователей. Дни графика считаются в UTC. Таблицы показывают до 100 групп с предупреждением о превышении.

## Телефон по USB

Для демонстрационного APK с адресом сервера `http://127.0.0.1:8080` выполните:

```bash
adb reverse tcp:8080 tcp:8080
```

Если сервер запущен на другом порту компьютера, измените второй порт. Например, для порта 18084:

```bash
adb reverse tcp:8080 tcp:18084
```

После действий в приложении подождите 35–60 секунд и обновите панель. APK передаётся отдельно и не входит в серверный образ. Полный сценарий — [LAB2_ANDROID.md](LAB2_ANDROID.md).
