# Ручная проверка ЛР4 0.0.4

Проверяйте на отдельном тестовом проекте: действия создают настоящие события. Автоматические результаты и ограничения — [LAB4.md](LAB4.md).

## Запуск и прежние три функции

- [ ] По командам README запускаются app/db/dashboard без сборки и мастера настройки. На странице и панели видна 0.0.4.
- [ ] На новом томе демонстрационная статистика пуста и оформлена; главная, форма, статистика и отказ связаны кнопками.
- [ ] Событие из формы появляется в Grafana после обновления; повтор той же формы не удваивает запись.
- [ ] Пустое имя даёт понятный отказ без увеличения счётчика.
- [ ] После `docker compose down` и `docker compose up -d --wait` прежние записи сохраняются. Не применять `-v`.

## Кабинет

- [ ] Регистрация, вход, ошибка неверного пароля и выход работают. Обновление страницы сохраняет сеанс.
- [ ] Проект создаётся, переименовывается; приложение получает отдельный ключ, после обновления видна только маска.
- [ ] Второй владелец не видит первый проект и не открывает его прямые ссылки статистики.
- [ ] События двух приложений разделены в панели и JSON статистики.
- [ ] Замена/отзыв ключа останавливает приём со старым ключом; новый принимает.
- [ ] Архивирование останавливает приём и сохраняет историю; после снятия архива действующий ключ снова работает.
- [ ] После пересоздания app остаются владельцы, проекты, ключи и сеанс, а Grafana снова открывает панель.

## JavaScript SDK

- [ ] Script и ES module подключаются по инструкции. В `/sdk-demo` origin совпадает с Web-приложением.
- [ ] Открытие экрана и клик подтверждаются сервером и видны в панели; в диагностике очередь опустошается.
- [ ] При отключении сети события ждут; после восстановления приходят с прежними ID без удвоения.
- [ ] Выключение сбора очищает очередь и не создаёт новых событий; выбор сохраняется после обновления страницы.
- [ ] Для `persist: true` очередь переживает обновление страницы; один namespace не используется одновременно несколькими вкладками.
- [ ] Сайт с другим origin получает отказ. Ключ отправки не открывает кабинет и статистику.

## Android

- [ ] Взять новый ключ Android-приложения из кабинета, пересобрать debug APK и выполнить USB reverse.
- [ ] Проверить открытие экрана, нажатие и успех сохранения; нажатие не подменяет успешную операцию.
- [ ] Повторить действия без сети, затем вернуть сеть и проверить доставку без удвоения.
- [ ] Проверить отсутствие влияния сетевого сбоя аналитики на сохранение модели.

## Интерфейс

- [ ] Светлая и тёмная темы читаемы; выпадающие списки оформлены; 390 и 1280 px не требуют прокручивать всю страницу по горизонтали.
- [ ] Полноэкранная Grafana и обратные ссылки открываются; никаких служебных паролей и ключей в URL/скриншотах.
- [ ] Для отчёта использовать только светлую тему.

На текущем выпуске автоматические проверки выполнены на Intel; базовый запуск ARM64 — под эмуляцией. Новую физическую проверку телефона с ключом кабинета пользователь выполняет отдельно.
