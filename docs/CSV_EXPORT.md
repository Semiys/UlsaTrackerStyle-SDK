# Экспорт CSV и JSON

В статистике приложения нажмите **«Скачать CSV»** или **«Скачать JSON»**, затем выберите сводку либо подробные события. Выбранный на панели период и часовой пояс устройства переносятся в выгрузку. Оба формата доступны в локальной версии 0.10.1.

| Вариант | Содержимое | Когда выбрать |
|---|---|---|
| Сводка по действиям | Группы по событию, экрану, кнопке/действию, платформе и версии; число событий и сеансов в группе | Анализ популярности экранов и кнопок, небольшой файл для нейросети |
| Подробные события | Одна строка на событие, идентификаторы события/сеанса, время и свойства | Разбор последовательностей и собственные расчёты |

Время подробного файла присутствует и в UTC, и в часовом поясе устройства со смещением. В каждом файле указаны границы периода и часовой пояс. Обе границы диапазона включительны. Для «За весь период» `period_mode=all`, начальная граница пустая: учитываются все сохранённые события до момента скачивания. После выбора периода данные выгрузки фиксируются на момент нажатия кнопки.

Сводка не содержит идентификаторов отдельных сеансов и полного JSON свойств. `sessions_in_group` — число уникальных сеансов именно в строке; складывать эти числа для получения общего количества сеансов нельзя. Клик и успешное действие — разные события. Один сеанс может присутствовать в нескольких строках.

CSV записан в UTF-8 с BOM, разделитель — запятая. Кавычки, переносы строк и кириллица сохраняются. Если Excel открыл один столбец, используйте «Данные», «Из текста/CSV», кодировку UTF-8 и разделитель «запятая». Текстовые ячейки, похожие на формулу, получают защитный апостроф. Счётчики сохраняются числами.

Для обоих форматов максимум — 10 000 записей и 8 МиБ; общий лимит CSV + JSON — шесть выгрузок в минуту на владельца (в демонстрации — на IP). При превышении лимита файл не обрезается: выберите меньший период или сводку. Большой запрос также ограничен по времени и памяти. Пустой период даёт CSV только с заголовками или JSON с `rows: []` и `row_count: 0`.

Владелец скачивает только своё приложение. Публичная демонстрация содержит только демонстрационный проект. Экспортёр не добавляет служебные ключи SDK, пароли и реквизиты кабинета. Подробный файл содержит свойства, которые передал клиент; состав событий контролирует разработчик. Готовые CSV и JSON создаются в памяти ответа и не сохраняются отдельными файлами на сервере; исходные события продолжают храниться в ClickHouse. Сервис не отправляет экспорт в нейросеть.

## JSON: структура файла

JSON предназначен для программной обработки и анализа в нейросетях. Он записан в UTF-8 без BOM. Счётчики сохраняются числами, свойства подробных событий — объектом `properties` с исходными строками, числами, boolean и null. CSV содержит свойства строкой в `properties_json`; JSON дополнительного разбора этой строки не требует. Текстовые значения JSON сохраняются без защитного апострофа, используемого для CSV-формул.

Метаданные находятся один раз в начале документа, а не в каждой записи:

```json
{
  "format_version": 1,
  "export_type": "summary",
  "period": {
    "mode": "range",
    "start_utc": "2026-10-31T20:00:00.000Z",
    "end_utc": "2026-11-01T12:00:00.000Z",
    "time_zone": "Europe/Astrakhan"
  },
  "row_count": 1,
  "rows": [{
    "event_type": "button_click",
    "screen": "collection",
    "button": "add_model",
    "action": "",
    "platform": "android",
    "app_version": "1.5",
    "event_count": 9,
    "sessions_in_group": 2
  }]
}
```

`format_version` — версия структуры выгрузки, независимая от HTTP-контракта SDK. `row_count` — число записей в `rows`: в сводке это количество групп, а не сумма событий. Для всей истории `period.mode = "all"`, `period.start_utc = null`; `end_utc` фиксирует момент отсечения выгрузки.

Подробный вариант имеет `export_type: "events"`. В строке находятся `event_id`, `session_id`, `event_type`, `screen`, `platform`, `app_version`, `occurred_at_utc`, `occurred_at_local`, `received_at_utc`, `received_at_local`, `properties`. Повторная доставка события не добавляет вторую строку.

У Grafana есть собственный [инспектор JSON данных панели](https://grafana.com/docs/grafana/latest/visualizations/panels-visualizations/panel-inspector/) и [экспорт настроек дашборда](https://grafana.com/docs/grafana/latest/visualizations/dashboards/share-dashboards-panels/). Кнопка сервиса формирует общий файл аналитики через защищённый экспорт данных, поэтому не зависит от открытой панели, её лимита отображения или внутренних имён полей Grafana.

## Пример запроса к нейросети

```text
Проанализируй выгрузку продуктовой аналитики в CSV или JSON. event_count — число событий, sessions_in_group — уникальные сеансы только внутри строки; не суммируй их как общее число сеансов. Отдельно рассматривай screen_view, button_click и action_success. Укажи популярные экраны и кнопки, доли и наблюдаемые закономерности. Не делай выводов об уникальных пользователях, конверсии или причинах поведения, если в файле нет нужных данных. Отметь ограничения анализа и предложи три проверяемые продуктовые гипотезы.
```

## Проверить вручную

- [ ] Выбрать день, скачать сводку и сравнить сумму `event_count` со счётчиком событий за тот же фиксированный диапазон.
- [ ] В CSV и JSON скачать подробный файл: число строк совпадает со сводкой, повторная доставка не удваивает записи.
- [ ] Выбрать «За весь период» и ручные даты; проверить `period_mode`, границы и местное время.
- [ ] Проверить кириллицу, кавычки и свойства с переносом строки.
- [ ] Выбрать пустой период: CSV содержит только заголовки, JSON — пустой `rows`.
- [ ] На компьютере и телефоне проверить обе темы, закрытие окна, сообщение об ошибке и папку загрузок.

- [ ] В JSON проверить числовые счётчики, объект `properties` и совпадение идентификаторов событий с CSV за одинаковый фиксированный диапазон.
- [ ] После шести скачиваний, чередуя CSV и JSON, следующая попытка объясняет ограничение; смена формата не обходит его.
- [ ] Закрыть окно кнопкой и Escape: фокус возвращается на кнопку выбранного формата; название окна и сообщения меняются при переходе между CSV и JSON.

## Проверка версии 0.10.1

Автоматический прогон: 107/107 тестов без пропусков, включая точные границы периода, дедупликацию, сводку, пустой результат, байтовый/строчный предел, общий лимит скачиваний и отказ чужому владельцу. В браузере через кнопки скачаны сводка и события JSON: сумма событий сводки совпала с числом подробных записей. Изначальные CSV-сценарии сохранены. Дополнительно 11/11 проверок CSV/JSON выполнены в ARM64-образе под эмуляцией; нативное ARM-устройство не использовалось. Проверены светлая/тёмная темы, ширина телефона 390 px без горизонтального переполнения, закрытие кнопкой и Escape с возвратом фокуса.
