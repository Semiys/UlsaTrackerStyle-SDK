# Выпуск 0.9.0

Сервер и образ продукта — **0.9.0**. Kotlin SDK — **0.2.0**, JavaScript SDK — **0.1.1**. Android APK для этих изменений пересобирать не требуется.

Добавлены CSV-сводка и подробные события за выбранный период. В выпуск также входят накопленные изменения после 0.0.4: инструкция подключения SDK, календарь, текущий местный день по умолчанию, вся история, часовой пояс устройства, анализ переходов между экранами, исправления памяти ClickHouse и повторной доставки JS SDK.

## Запуск опубликованного продукта

```bash
git clone --branch v0.9.0 --depth 1 https://github.com/Semiys/UlsaTrackerStyle-SDK.git
cd UlsaTrackerStyle-SDK
docker compose -f docker-compose.yml -f docker-compose.release.yml pull
docker compose -f docker-compose.yml -f docker-compose.release.yml up -d --wait
```

Откройте http://localhost:8080. Нужны свободные порты 8080 и 3000. `docker-compose.release.yml` выбирает образ `semiys/ulsatrackerstyle-sdk:0.9.0` и соответствующий заголовок Grafana. В корневом файле нет сборки; Docker выбирает Intel/ARM автоматически. Данные существующего проекта сохраняются в прежних томах. Не добавляйте `down -v`, если хотите сохранить события и кабинет.

## Связь с лабораторными

Экспорт CSV — развитие продукта сверх задания ЛР4. В методичке ЛР4 новые функции не входят в требуемый объём. Сдаваемый снимок остаётся в ветке `lab4`, PR №4 и образе `semiys/ulsatrackerstyle-sdk:0.0.4`; этот тег не заменяется новым выпуском. Команды отчёта ЛР4 используют именно ветку `lab4`. Описание следующих работ составляется по их фактическим требованиям; наличие новой функции не означает, что она является обязательным заданием следующей работы.

Проверки и список ручных сценариев: [TESTING.md](TESTING.md), [CSV_EXPORT.md](CSV_EXPORT.md). Физический ARM и iOS не входят в этот прогон; Android SDK и мобильный код не изменялись.
