# Испытания от 16.11.2026 – версия 0.12.1

Проверялась локальная сборка текущих исходников. Коммит, push и публикация Docker-образов в этом этапе не выполнялись. Предыдущие лабораторные образы не перезаписывались.

## Исправления

- Настраиваемый лимит INGEST_RATE_LIMIT_REQUESTS: по умолчанию 1200 запросов за 60 секунд на ключ; допустимы 1–60000.
- Одна согласованная агрегация ClickHouse для сводки вместо семи запросов.
- Объединение соседних пакетов одного приложения: до 1000 событий, окно 5 мс. Подтверждение выдаётся после записи событий и следов.
- Ограниченный буфер 64 запросов записи и прежняя очередь 32 операций БД. Проверены переполнение, последующий приём и границы удаления.
- Отказ операции закрывает группу для новых пакетов, чтобы восстановление не оставляло зависший запрос.
- Прокси использует отдельное upstream-соединение на запрос и не повторяет оборванный POST самостоятельно. Транспортная диагностика содержит только фиксированный код ошибки и признак повторного использования сокета.
- Новые операционные следы записываются напрямую из проверенных метаданных; чтение следов выполняется для повторов. Сохранены исходное время приёма, восстановление после частичного отказа и подтверждение после обеих записей.

## Полная нагрузка П14

Подготовлены 100 000 событий через валидируемое хранилище. После минутного прогрева – 600 HTTP-запросов и 12 000 принятых событий – выполнены 6000 запросов по 20 событий за десять минут, по 10 запросов/с. Все 6000 получили HTTP 200; все 120 000 UUID и подтверждений сверены с events FINAL и ingestion_receipts FINAL. p95 успешных подтверждений – 430,750 мс; p99 – 612,693 мс. Все 438 обращений к сводке и панели Grafana завершились без ошибок.

Шесть контейнеров используют общий набор четырёх логических CPU; сумма лимитов памяти – 4 ГиБ, swap выключен. Хост Docker: Intel/amd64, 16 CPU, 7,63 ГиБ. Это ограниченный стенд на общем компьютере, а не отдельный VPS. RSS API не является памятью всего стенда.

Первый полный прогон 0.12.0 дал 1200 HTTP 200 и 4800 HTTP 429. Промежуточные повторы 0.12.1 дали 5994/6 (200/503), затем 5999/1 (200/502) и 5980/20 (200/503). Их журналы сохранены отдельно; они не объявлены успешными. Неподтверждённые пакеты не отнесены к потере подтверждённых данных.
