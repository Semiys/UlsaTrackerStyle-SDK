# Оформление отчётов

Уточнения пользователя для ЛР1, ЛР2 и следующих отчётов:

- Перед каждой таблицей нужен абзац со ссылкой на её номер и объяснением содержания.
- После таблицы нужен вывод или пояснение, связанное с её данными.
- Перед каждым рисунком нужен текст со ссылкой на его номер.
- Подписи рисунков: Times New Roman, курсив, 11 пт.
- Подписи таблиц: сохранять исходное оформление по образцу пользователя; требование «курсив, 11 пт» к ним не относится. Оформление подписей таблиц в ЛР1 и ЛР2 пользователь исправляет самостоятельно.
- Снимки сайта для отчётов делаются только в светлой теме, чтобы их было удобно печатать.
- Нельзя обрезать текст или важные элементы снимка для размещения на странице.
- Отдельный титульный лист сохраняется. Принудительные разрывы и большие интервалы в основной части используются только при необходимости.
- Таблицы, изображения и подписи проверяются после экспорта Google Docs в PDF, на каждой странице.
- Светлая и тёмная палитры сайта соответствуют темам мобильного приложения «Дом Коллекционера».
- Исправления вносить в существующие Google Docs, сохраняя правки пользователя и ссылки.
