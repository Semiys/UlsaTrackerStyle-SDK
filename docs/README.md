# Документация UlsaTrackerStyle SDK

Подключите SDK к приложению, отправьте события и проверьте статистику. Сейчас реализованы Android и JVM, версия SDK — **0.2.0**. JavaScript SDK 0.1.1 также реализована; iOS запланирован. До публикации в Maven библиотека подключается локально через Gradle composite build.

Начните с [кабинета](CONSOLE.md): регистрация, проект, приложение и ключ. Для сайта используйте [JavaScript SDK](../sdk/js/README.md).

На сайте есть страница подключения: `/guide`. Она доступна из общего меню и ведёт от создания проекта до первого события. Для текущих исходников 0.10.1 используйте [запуск с мониторингом](MONITORING.md).

## Начать работу

1. [Запустите сервер](../README.md#запуск-продукта) — текущий стенд с ClickHouse и веб-панелью.
2. [Подключите Android SDK](../sdk/kotlin/README.md#локальное-подключение-к-android-проекту) — зависимость, инициализация и настройки подключения.
3. [Отправьте первое событие](SDK_API.md#подключение-и-методы) — пример и правила публичного API.
4. [Проверьте события на телефоне](SDK_CHECKLIST.md) — ожидаемые счётчики и сценарии без связи.
