## Подключение к серверу

1. Запустите образ ЛР2 по README и убедитесь, что главная открывается на компьютере. На новом volume проект называется «ЛР2 · Дом Коллекционера».
2. На телефоне включите режим разработчика и отладку по USB. Подключите его, разблокируйте и разрешите отладку для компьютера. На MIUI отдельно может понадобиться разрешение установки по USB.
3. Установите APK через файловый менеджер телефона или `adb install -r`. Android Studio не обязательна: достаточно официальных [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools).
4. Проверьте соединение и настройте обратный порт:

```bash
adb devices
adb reverse tcp:8080 tcp:8080
```

5. Если сервер опубликован на **18084**, вторая команда — `adb reverse tcp:8080 tcp:18084`; если на **8081** — `adb reverse tcp:8080 tcp:8081`. Первый порт — адрес SDK на телефоне, второй — порт компьютера.
6. Откройте приложение, перейдите между вкладками, нажмите «+», сохраните тестовую модель. Через 35–60 секунд обновите `/dashboard` компьютера. Должны появиться события с платформой `android`.
7. После переподключения USB восстановите `adb reverse`. При двух телефонах указывайте устройство: `adb -s СЕРИЙНЫЙ_НОМЕР reverse tcp:8080 tcp:8080`.

Для телефона не нужен Docker. Сервер и графики работают на компьютере; SDK лишь сохраняет небольшую очередь и отправляет пакеты.

## Если APK не устанавливается

Этот APK имеет тот же applicationId, что обычное приложение. Он может обновить debug-сборку с той же подписью; поверх release с другой подписью Android его не установит. Для демонстрации проще отдельный тестовый телефон. Перед удалением установленного приложения экспортируйте нужную коллекцию: удаление приложения удаляет его локальные данные.

## Повторная сборка разработчиком

В PowerShell из папки `D:\AndroidDekstops\DomCollection`:

```powershell
.\gradlew.bat --gradle-user-home 'D:\AndroidProjectGradle\DomCollectionGradle' :androidApp:assembleDebug '-Dorg.gradle.java.home=D:/ProgramsCity/jbr' '-PulsaTracker.sdkPath=D:/MyTracer SDK CopyStyle/sdk/kotlin' '-PulsaTracker.endpoint=http://127.0.0.1:8080' '-PulsaTracker.ingestKey=ulsa_lab2_demo_ingest_2026_local_project_only' --offline
```

Пути соответствуют компьютеру разработчика. На новом ПК используйте свои пути и снимите `--offline`, если зависимости ещё не скачаны. Результат: `androidApp/build/outputs/apk/debug/androidApp-debug.apk`.

Параметры переданы только этой сборке. Обычные `local.properties`, исходники и конфигурация release мобильного приложения не изменялись. Аналитика UlsaTrackerStyle в release этой сборкой не включается.
