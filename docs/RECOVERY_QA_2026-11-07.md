# Проверка резервирования и восстановления — 07.11.2026

Инструмент 0.1.0, формат комплекта 1; восстановленный сервис 0.11.2. Среда: Docker Desktop, Linux/amd64. Исходный проект mispisit-sarantsev был остановлен. Назначение — отдельный ulsa-recovery-proof, новые тома и сети; кабинет на http://127.0.0.1:18088. [Команды и ограничения](BACKUP_AND_RESTORE.md).

## Что выполнено

Холодная копия пяти writable-томов, конфигурации и секретов сохранена вне Git. Включены шесть различных Docker-образов по фактическим image ID. Все файлы комплекта имеют SHA-256. Отпечаток тома учитывает содержимое файлов, относительные ссылки, владельцев и права; до/после архивирования он совпал. После извлечения в новые тома совпали все пять отпечатков. Все шесть восстановленных сервисов достигли healthy.

В первом проходе экспорт остановился из-за отсутствовавшего образа старого остановленного контейнера Grafana оператора. Её контейнер пересоздан на согласованной уже имеющейся Grafana 13.3.0 с прежним томом, проверен и снова остановлен. Затем комплект создан заново. В инструмент добавлена проверка наличия всех образов до большого копирования. Незавершённая первая папка не использовалась для восстановления.

## Измерения

| Показатель | Результат |

| Полный автоматический прогон в копии | **134/134**, ошибок и пропусков нет |

Время восстановления включает проверку файлов, извлечение, сверку томов и ожидание запуска контейнеров. Импорт images.tar проверен отдельно: Docker принял архив; ранее существовавшие теги не изменились. На этом хосте образы уже были в кеше, поэтому измерение RTO не включает перенос комплекта по сети на новую машину.

Источником была остановленная система: во время создания копии подтверждённых сервером новых записей не появлялось. Все файлы снимка восстановлены без отличий. Это проверка точки восстановления холодной копии; допустимый RPO действующего сервиса, расписание копий и потери при аварии питания ещё требуют отдельных испытаний.

## Проверки отказов и изоляции

- Попытка восстановить поверх исходного проекта отклонена до создания назначения.
- Попытка использовать уже существующий целевой том отклонена; созданный пустой тестовый том после проверки удалён.
- Отдельная конфигурационная копия намеренно повреждена. Контрольная сумма не сошлась, новый проект и тома не появились.
- Проверены ограничения путей, точные image ID, отсутствие внешних томов/сетей, read-only bind mounts только из каталога назначения и локальные порты.
- Кабинет копии использует 127.0.0.1, чтобы его cookie не смешивались с основным localhost-кабинетом.

## Сохранность исходных данных

До функциональных испытаний в восстановленной базе было **171 исходное событие**. После всех тестов каждое найдено с прежним содержимым. Совпали хеши 9 исходных строк в 6 таблицах аккаунтов и конфигурации. Проверены владельцы, проекты, приложения, ключи, настройки и соответствия Grafana.

Тесты добавили в копию 452 синтетических событий и свои временные аккаунты/проекты. Они не относятся к исходной пользовательской статистике. В конце все пять исходных томов повторно подключены только для чтения: их отпечатки по-прежнему совпали с manifest. Основные контейнеры остались остановлены. Работа выполнялась с копией, без удаления/перезаписи исходных томов.

134 проверки включают API, вход/CSRF, изоляцию владельцев, ключи, Android HTTP-контракт, JavaScript SDK с повторной доставкой, Grafana, периоды/часовые пояса, CSV/JSON, мониторинг, удаление приложения и пять новых проверок инструмента восстановления.

## Границы

Восстановление проверено в новых томах на том же Docker-хосте. Другой физический хост, ARM64, потеря площадки, внешнее зашифрованное хранилище, автоматическое расписание и резервирование без остановки пока не проверены. Приватный комплект и сырые контрольные данные не публикуются в репозитории.

Телефон TECNO доступен; установлен ru.semius.domcollection 1.5 (8), debug/test-only. Установленный APK отличается от текущего локального debug-артефакта. Подходящего instrumentation APK для этого package нет; присутствует отдельный physicaltest-вариант. APK не переустанавливался, мобильные исходники/коллекция этим проходом не изменялись. Проверку именно установленной сборки SDK не подменяем чтением конфигурации другого локального APK.
